# Catálogo de Colchones, Camas y Escaparates

Catálogo web estático listo para GitHub Pages.

## Flujo de carga provisional
1. Abre `agregar-producto.html` en tu navegador para cargar visualmente colchones, camas y escaparates sin editar código.
2. Haz clic en **Descargar JSON** para guardar `productos.json`.
3. Sube ese `productos.json` a la raíz de tu repositorio en GitHub y elimina `agregar-producto.html`.
4. `index.html` mostrará el catálogo completo listo para vender.
